# Project Plan

Source: CS0011 Final Project activity sheet (Proposed Database-Driven Android Application, 100 points, group of 5).

**Deadline:** around the end of November (to confirm).
**Current stage:** proposal planning. The instructor must approve the proposal before development.

## Grading at a Glance

| Part | Points |
| --- | --- |
| Android application | 70 |
| Documentation | 30 |

Application: Problem solution and core functions 15, Database and CRUD 20, Navigation and data transfer 10, Interface and usability 10, Validation, feedback and reliability 8, Additional feature 7.

Documentation: Proposal and project definition 6, Database, screen and navigation design 7, Testing, defects and improvements 10, User guide and visual evidence 4, AI-use declaration 3.

## Minimum App Requirements Checklist

- [ ] Android Studio and Kotlin
- [ ] At least 3 functional screens or Activities
- [ ] Explicit Intents with meaningful data passed between screens
- [ ] SQLite (or an approved database) with complete CRUD and persistent records
- [ ] Required-input validation
- [ ] Clear success, error, empty-state and confirmation messages
- [ ] Proper Android resources, usability and accessibility
- [ ] At least one feature beyond CRUD (search, sorting, filtering, categories, notifications, JSON import, reports, export, preferences, image attachment or authentication)
- [ ] At least 12 documented test cases
- [ ] At least 3 documented defects and their corrections
- [ ] At least 2 improvements based on testing evidence

## Part 1 Proposal Outline

The proposal has to contain these items, in this order.

1. Application title and category
2. Problem statement and target users
3. Proposed solution
4. One general objective and at least three specific objectives
5. Core features
6. Database technology and data to be stored
7. Tables, fields, primary keys and relationships
8. Screen and navigation plan
9. Initial wireframes of the major screens
10. At least one additional feature beyond CRUD
11. Development schedule
12. AI-use plan (low priority for now)

## Submission Files

- Project ZIP: complete Android Studio project folder
- APK: installable and working
- Proposal: instructor-approved
- Documentation PDF: design, database, user guide, testing, defects, improvements, screenshots, AI declaration
- Demonstration: short presentation and demo

File names: `Surname_FirstName_ProjectTitle.zip`, `Surname_FirstName_ProjectTitle.apk`, `Surname_FirstName_Documentation.pdf`.

Before submitting, check that every file opens and that the APK installs and runs.

## Steps

1. Pick the idea as a group (see `IDEAS.md`).
2. Fix the architecture (see `ARCHITECTURE.md`).
3. Write the proposal and get instructor approval.
4. Build in small steps, one branch per feature.
5. Test: 12 test cases, 3 defects found and fixed, 2 improvements from the evidence.
6. Write the documentation and take labeled screenshots.
7. Check every file, then submit.
