# Test Execution Log (TC-01 to TC-29)

Final result: **29 Pass, 0 Fail, 0 Inconclusive, 0 Pending.** Three cases (TC-17, TC-20 and TC-28) failed on their first run on 2026-11-21 and passed on the retest after the fix; their rows below show the final status and describe the first run. Two more defects (D-04 in the Medications list, D-05 in the Report empty state) were found while checking TC-01 and TC-08 again, and two improvements (I-01, I-02) were made; see `DEFECTS_AND_IMPROVEMENTS_LOG.md`. The extra pass found nothing new.
